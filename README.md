# E-Commerce-Sales-Analysis-PowerBI
Interactive E-Commerce Sales Analysis dashboard built with Microsoft Power BI to analyze sales, profit, customers, products, regions, shipping and business performance.
# 📊 Project Overview

This project presents an interactive E-Commerce Sales Analysis Dashboard developed using Microsoft Power BI.

The objective is to transform raw e-commerce transaction data into meaningful business insights by analyzing sales performance, profitability, customer segments, product categories, regional performance, shipping modes, discounts, and order trends.

The project demonstrates an end-to-end Power BI workflow, including data preparation, data modeling, DAX-based KPI creation, interactive visualization, and business-oriented analysis.
# 🎯 Business Objectives

The dashboard was developed to answer key business questions such as:

How are overall sales and profit performing?
Which product categories and sub-categories generate the most sales?
Which regions and markets contribute the most revenue?
Which customer segments drive business performance?
How do discounts affect profitability?
Which products contribute significantly to sales and profit?
How are sales changing over time?
Which shipping modes are most frequently used?
Where are potential opportunities for improving profitability?
